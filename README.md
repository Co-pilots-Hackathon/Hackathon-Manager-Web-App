Problem:
 • Entry queues create delays and crowding
 • Resource distribution is hard to track
 • No centralized system to record and analyze  
    judges scores

Proposed Solution :
 • Participants upload valid ID proof during  
   registration 
 • Each participant gets a unique QR at registration
 • QR is scanned for entry and resource access
 • Admin dashboard tracks participation in real time
 • Judges evaluate directly on a digital scoring panel

Frontend: HTML, CSS, JavaScript
Backend: Node.js
Database: MongoDB, Firebase
QR System: npm-based QR generation & verification
Analytics: OpenCV
